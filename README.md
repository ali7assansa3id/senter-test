## ما تم تنفيذه
- الحسابات والأدوار: مالك / مدير / موظف / مدرس (RBAC) — تشفير scrypt، توكن موقّع، حد لمحاولات الدخول.
- السناتر: فروع وقاعات.  الطلاب.  المدرسون.
- المجموعات (سعة، تسجيل طلاب)، الجداول الأسبوعية، توليد الحصص، منع تعارض القاعة/المدرس.
- الحضور اليدوي (حاضر / غائب / متأخر / بعذر) — بدون QR.
- كل جدول فيه tenant_id وحذف ناعم (deleted_at)، وكل استعلام مقيّد بالـ Tenant.
- المدرس يرى ويسجّل حضور مجموعاته فقط.

## المرحلة الثانية (المالية) — ما تم تنفيذه
- الخزائن: رصيد افتتاحي + رصيد محسوب لحظياً، خزينة لكل فرع أو مركزية، منع الرصيد السالب.
- الاشتراكات: طالب + مجموعة + شهر، مع خصم؛ يُشترط أن يكون الطالب مسجلاً بالمجموعة؛ منع التكرار.
- التحصيل: إيصالات بأرقام متسلسلة لكل سنتر، منع الدفع الزائد، طباعة الإيصال.
- BR-004 (مفترض): الإيصال والمصروف والصرف لا تُعدّل ولا تُحذف، بل تُلغى بسبب إلزامي.
- BR-002 (مفترض): عزل مالي كامل بين السناتر، وموظف/مدير الفرع يرى حسابات فرعه فقط.
- المصروفات، مستحقات المدرسين (نسبة % من المحصّل أو مبلغ ثابت شهرياً) وتسوية الصرف.
- التقارير: ملخص مالي، إيرادات، مصروفات، ديون، تحصيل شهري، مستحقات مدرسين — عرض + Excel حقيقي (.xlsx) + PDF عبر الطباعة (حفظ كـ PDF من المتصفح).

## المرحلة الثالثة (حسابات الطلاب وأولياء الأمور والإشعارات)
- حساب الطالب وحساب ولي الأمر (دور `student` و`parent`) — يُنشئهما الموظفون فقط، الدخول برقم الهاتف.
- ولي الأمر يُربط بأكثر من طالب (أب/أم/وصي)، ويمكن فك الربط فيُقطع وصوله فوراً.
- لوحة الطالب/ولي الأمر: الجدول الأسبوعي والحصص القادمة، الحضور وملخصه، الاشتراكات والمتبقي، المدفوعات وطباعة الإيصالات.
- الإشعارات داخل التطبيق: غياب (FR-052)، تأخر، إلغاء/تعديل موعد حصة؛ عدّاد غير مقروء، تعليم مقروء، وتفضيلات لكل نوع.
- BR-005 (مفترض): الطلاب قُصّر افتراضياً — لا يُعرض لأي حساب إلا بياناته أو أبناؤه المرتبطون، ولا تُعرض الهواتف أو الملاحظات
  أو بيانات أي طالب آخر، والحسابات تُنشأ بمعرفة الموظفين فقط، والتعطيل أو فك الربط يسري فوراً.
- تسجيل الدخول يدعم نفس رقم الهاتف في أكثر من سنتر (يُطابَق مع كلمة المرور).

## المرحلة الرابعة (المحتوى والامتحانات والدروس الإلكترونية)
- **الدروس:** مباشرة (رابط خارجي http/https + موعد بتوقيت القاهرة) ومسجّلة (رابط أو فيديو mp4/webm مرفوع)، مع نشر/مسودة ومتابعة تقدم كل طالب (استئناف من آخر نقطة، اكتمال عند 90%).
- **المذكرات:** مكتبة منظمة حسب المادة والصف، ملفات PDF/Word/PowerPoint/Excel/صور حتى 25MB، إتاحة «لمشتركي المجموعة» أو «مجانية لطلاب الصف».
- **بنك الأسئلة:** اختيار من متعدد، متعدد الإجابات، صح/خطأ، إجابة قصيرة (تصحيح آلي مع تطبيع العربية)، ومقالي (يدوي).
- **الامتحانات والواجبات:** نافذة زمنية ومدة ومحاولات متعددة وترتيب عشوائي، حفظ تلقائي، تسليم تلقائي عند انتهاء الوقت، واجب بتسليم ملف، تصحيح آلي/يدوي،
  إعلان النتائج (يدوي أو فوري)، إظهار الإجابات الصحيحة اختيارياً، إحصاءات. الأسئلة تُنسخ داخل الامتحان فلا يغيّرها تعديل البنك لاحقاً.
- **ربط المحتوى بالاشتراكات (افتراض):** يصل الطالب لمحتوى مجموعته فقط إذا كان مسجلاً فيها ولديه اشتراك نشط للشهر الحالي عليه دفعة صحيحة واحدة على الأقل؛ وإلا يظهر المحتوى «مقفلاً» بلا رابط.
  إلغاء الدفعة يقفل البث فوراً. (راجعها مقابل SRS: قد تريد اشتراطاً أشد مثل السداد الكامل.)
- **حماية المحتوى:** لا مسارات ملفات مباشرة؛ روابط موقّعة تنتهي بعد 10 دقائق وتُفحص الصلاحية عند كل طلب بث، دعم Range، `no-store`، علامة مائية باسم الطالب، منع التنزيل/القائمة اليمنى في المشغّل،
  وفحص نوع الملف بمحتواه (magic bytes). تنبيه: لا توجد حماية تقنية كاملة ضد تصوير الشاشة.
- **المدرس:** يدير محتوى مجموعاته وأسئلته فقط. **ولي الأمر والطالب:** نتائج الامتحانات وتقدم الدروس لا تظهر إلا بعد إعلان النتيجة.
- الملفات تُحفظ في مجلد `uploads/` (أو `UPLOAD_DIR`) — يجب نسخه احتياطياً مع قاعدة البيانات.

## النشر (الإصدار 1.0.0)

**المتطلبات:** Node.js 22 أو أحدث. لا توجد حزم npm خارجية (لا حاجة لـ `npm install`).

**تشغيل بسيط:**
```bash
cp .env.example .env   # ثم عدّل القيم (خصوصاً SECRET و SUPER_ADMIN_*)
set -a; . ./.env; set +a
npm start
```

**Docker:**
```bash
docker build -t senter .
docker run -d -p 3000:3000 -e SECRET=... -e SUPER_ADMIN_PHONE=01xxxxxxxxx -e SUPER_ADMIN_PASSWORD=... -v senter-data:/data senter
```
البيانات (قاعدة SQLite والملفات المرفوعة والنسخ) في المجلد `/data` — اربطه بوحدة تخزين دائمة.

**متغيرات البيئة:**

| المتغير | الوظيفة |
|---|---|
| `PORT` | المنفذ (3000) |
| `SECRET` | مفتاح توقيع التوكنات — **اضبطه في الإنتاج** |
| `DB_FILE` | ملف قاعدة SQLite |
| `UPLOAD_DIR` | مجلد الملفات المرفوعة |
| `BACKUP_DIR` | مجلد النسخ الاحتياطية |
| `ANTHROPIC_API_KEY` / `ANTHROPIC_MODEL` | مفتاح ونموذج الذكاء الاصطناعي (اختياري) |
| `SUPER_ADMIN_PHONE` / `SUPER_ADMIN_PASSWORD` | مشرف المنصة الأول (يُنشأ مرة واحدة) |
| `TRUSTED_PROXIES` | عناوين الوكلاء العكسيين الموثوقين لقراءة `X-Forwarded-For` بأمان |

**النسخ الاحتياطي:** `npm run backup` (أو `node scripts/backup.js [مجلد]`) — ينشئ نسخة متسقة أثناء التشغيل ويحتفظ بآخر 14 نسخة. اجدولها بـ cron.

**خلف nginx:** مرّر الرأس `X-Forwarded-For` وضع عنوان nginx في `TRUSTED_PROXIES`.

**الباقات:** السناتر الجديدة على باقة `basic`. تُفعّل باقة الذكاء وحصة التوكنات من لوحة إدارة المنصة (مشرف المنصة فقط).
